## Agent skills

### Issue tracker

Track issues and specs as local Markdown under `.scratch/`.
Read `docs/agents/issue-tracker.md` before creating or updating tickets.

### Triage labels

Use the five default triage roles.
Read `docs/agents/triage-labels.md` when assigning triage status.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Read `docs/agents/domain.md` before exploring domain terminology or decisions.
